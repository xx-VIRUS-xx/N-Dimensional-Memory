# EXP-V6 — Cross-Agent Persistent Memory

V6 tests whether persistent memory can remain independent of any one model/agent while preserving observations, provenance, disagreement, temporal evolution, and reconstructability.

## Versions
- V6: cross-agent proposition sharing
- V6.1: append-only shared memory protocol
- V6.2: deterministic shared-state reconstruction and conflict/evolution derivation

## Run
```bash
pytest -q
```
