# EXP-V5.2 — Temporal Belief History

## Question
Can competing beliefs about the same proposition be represented as temporally scoped observations, so that a later change is recognized as evolution rather than contradiction?

## Principle
A belief value is not a timeless truth. Preserve each observation, its validity interval, status, and provenance. Compare observations using temporal order before classifying conflict.

## Benchmark
- Observation 1: Rahul is in Jaipur, valid through May 2026.
- Observation 2: Rahul moved to Delhi in June 2026.

Expected result: temporal evolution, not unresolved contradiction.

## Important distinction
`observation history != current belief != timeless truth`

No observation is deleted when a later observation becomes current.
