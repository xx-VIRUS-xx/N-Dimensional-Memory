# EXP-V7.1 Results

## Executive Summary

V7.1 tested whether a structured V6 relational memory representation could support long-horizon conversational recall when historical evidence was diluted across a 1,200-event conversation corpus.

Two agents completed the run:
- Claude Code
- Copilot

Codex was excluded because of its rate-limit constraint and is not treated as a missing performance result.

The benchmark used four conditions:
- RAW
- deterministic lexical RAG
- V6 structured memory
- V6 + RAW

Both agents independently produced the same qualitative pattern: the only observed answer-level failure was the temporal-state case under RAG. V6 and V6+RAW completed all tested cases correctly.

## Results

### Claude

| Condition | Cases | Applicable checks | Correct | Incorrect | Unsupported claims |
|---|---:|---:|---:|---:|---:|
| RAW | 8 | 15 | 15 | 0 | 0 |
| RAG | 8 | 16 | 14 | 2 | 0 |
| V6 | 8 | 15 | 15 | 0 | 0 |
| V6+RAW | 8 | 16 | 16 | 0 | 0 |

Claude's RAG failure was V71-TIME-01. The retriever returned six chunks containing the early polling and webhook events but missed the later webhook-disable and webhook-reenable events. The agent correctly reported that the retrieved evidence was insufficient rather than inventing a latest state.

The Claude report verified that only 2 of the 4 required temporal signal events were present in the retrieved chunks. The failure was traced to retrieval coverage, not to the structured memory representation.

### Copilot

| Condition | Cases | Correct | Incorrect | Unsupported claims |

| RAW | 8 | 8 | 0 | 0 |
| RAG | 8 | 7 | 1 | 0 |
| V6 | 8 | 8 | 0 | 0 |

Copilot encountered the same RAG temporal case. Its retrieved evidence contained the early polling and webhook events but missed the later disable/re-enable events, so the latest state could not be established from the retrieved evidence alone.

## Shared Failure: Temporal Retrieval Coverage

The temporal case contains four relevant events:

1. E0233 — polling begins
2. E0401 — migration to webhooks
3. E0887 — webhooks disabled temporarily
4. E1190 — webhooks re-enabled

The bounded deterministic RAG policy retrieved chunks containing E0233 and E0401 but not E0887 or E1190.

Therefore RAG could establish only:

`polling → webhooks`

It could not establish the complete sequence or latest state:

`polling → webhooks → disabled → re-enabled`

Both agents treated this as an evidence boundary rather than hallucinating the missing state.

## V6 Memory Behavior

The V6 condition supplied structured memory without the raw conversation.

The temporal case was represented as a state history:

`polling → webhooks_active → webhooks_disabled → webhooks_active`

with validity intervals and a current-state field.

The ambiguity case preserved:

`he → {Rahul, Arjun} → unresolved`

The belief/conflict case preserved the progression from inference to later confirmation rather than replacing the earlier inference.

The negative-knowledge case preserved scoped absence, including the distinction between the billing migration review and a MongoDB mention belonging to another project.

The provenance case preserved the ordered roles of observation, confirmation, inference, later confirmation, and later memory read.

## Important Methodological Limitation

V7.1 did **not** test whether an LLM can reliably construct the V6 memory representation from arbitrary conversation.

The V6 memory was generated deterministically from benchmark annotations. Therefore the experiment tested downstream utility of the representation, not memory-extraction quality.

This distinction is critical. V7.1 supports:

> A structured relational memory representation can be consumed by multiple agents and can preserve the tested long-horizon temporal, relational, ambiguity, conflict, negative-knowledge, action/outcome, and provenance information.

It does not establish:

> V6 is universally superior to RAG.

Nor does it establish that an arbitrary model can construct the representation correctly.

## Additional Observation

One V6 case, V71-ACT-01, had no pre-derived relationship/state record in the benchmark memory. The agents reconstructed the action → outcome sequence by ordering three timestamped observation records. This shows that the substrate can still support reasoning over observations, but it also identifies an opportunity for a richer memory compiler.

## Measurements

Input-token counts and latency were not exposed by the manual provider-neutral execution environment. These fields were left null rather than fabricated.

## Conclusion

V7.1 produced a reproducible, cross-agent observation:

- RAW: all tested cases answered correctly.
- RAG: both agents experienced the same temporal retrieval-coverage failure.
- V6: all tested cases answered correctly from structured memory alone.
- V6+RAW: all tested cases answered correctly.

The result justifies moving to V7.2, whose purpose is to test the missing half of the problem: **can an agent construct the persistent memory itself, and can another model consume that generated memory without access to the original conversation?**
