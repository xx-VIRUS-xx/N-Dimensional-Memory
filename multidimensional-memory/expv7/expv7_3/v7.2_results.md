# EXP-V7.2 Results

## Executive summary
V7.2 tested whether independent agents could construct persistent structured memory from a long conversation and whether that memory could be consumed by the same or another model without the original conversation.

Two agents were used: Claude and Copilot. Codex was excluded because of rate limiting.

Both agents independently encountered the same genuine V7.2 schema/tooling defect: the supplied V7.1 schema/validator hardcoded the V7.1 condition enum and did not accept the new `V6-GENERATED` and `V6-GENERATED+RAW` condition names required by V7.2. The defect was disclosed rather than silently patched. A separate V7.2 schema was used.

## Downstream results

| Condition | Claude | Copilot |
|---|---:|---:|
| RAW | 8/8 | 8/8 |
| RAG | 7/8 | 7/8 |
| V6-GENERATED | 8/8 | 8/8 |
| V6-GENERATED+RAW | 8/8 | 8/8 |

The two RAG failures were the same temporal case, `V71-TIME-01`. Bounded deterministic lexical retrieval surfaced the early polling/webhook events but missed `E0887` and `E1190`, preventing reconstruction of the complete state history. Claude documented the same retrieval gap independently. This is evidence about that retrieval policy, not a universal RAG result.

## Memory construction

Both writers preserved the 20 distinct substantive source events.

Claude's generated memory contained 50 records: 20 observations, 14 relationships, 9 propositions, 3 state histories, 1 ambiguity, 1 belief history, 1 negative-knowledge record, and 1 provenance chain. Its evaluation reported observation precision and recall of 1.0 and zero invented source events.

Copilot's generated memory contained 31 records and likewise preserved all 20 unique substantive source events. Its deterministic source-event precision and recall were both 1.0. Free-text semantic equivalence was not independently scored.

The writers were not identical. They used different record IDs, predicates, state labels, and one relationship was represented as state-history information by Claude. These were evaluated as semantic/structural differences rather than factual omissions where the underlying information remained preserved.

## Cross-agent persistence

Claude → Copilot was completed with the frozen Claude memory artifact. Copilot reported 8/8 reader correctness and zero unsupported claims.

The reverse Copilot → Claude handoff was also executed in the complete result set. The key V7.2 result is therefore not merely same-agent recall: generated memory was usable across model boundaries.

## What V7.2 demonstrates

V7.2 provides evidence that:

1. Independent agents can extract the same underlying source-event set into structured persistent memory.
2. Agents can use different internal labels while preserving semantically equivalent information.
3. Generated memory can preserve temporal state, ambiguity, belief evolution, scoped negative knowledge, action/outcome structure, and provenance.
4. A second model can consume generated memory without the original conversation.
5. The same bounded lexical RAG policy can fail on a distributed temporal history that structured memory preserves.

## What V7.2 does NOT establish

The writer still had benchmark scaffolding available through the corpus/benchmark structure, including signal identification and event relevance information. Therefore V7.2 does not fully establish autonomous importance selection from arbitrary conversation.

It also does not establish that structured memory universally outperforms RAG, nor does it provide token/latency/cost measurements because those measurements were unavailable in the manual runs.

## Main limitation carried into V7.3

The next experiment must remove the writer-side scaffolding and measure importance selection itself:

`unlabeled long conversation → autonomous memory selection → structured memory → blind reader`

V7.3 is designed specifically for that gap.
