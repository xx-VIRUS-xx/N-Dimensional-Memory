# Writer Protocol

The writer's task is not query answering. It is durable-state formation.

Retain when supported:
- durable decisions and rationale
- actions and outcomes
- state transitions and current/obsolete state
- tentative/inferred/confirmed/disputed beliefs
- unresolved ambiguity
- scoped negative knowledge
- provenance and source IDs
- consequential failed attempts

Avoid:
- routine chatter
- duplicate observations unless repetition changes confidence/state
- treating discussion as decision
- treating intention as execution
- treating obsolete state as current
- unsupported causal inference
- query-driven retention

The writer must process all events and make selection decisions from semantics, not hidden labels or future questions.
