# Future Query Protocol

Queries are generated only after writer memory freeze.

For each domain create:
- direct recall
- paraphrase
- indirect reference
- temporal reconstruction
- causal question
- multi-hop relation/state question
- negative-knowledge question
- ambiguity question
- compositional query combining 2–4 durable facts

At least half of the queries must use wording not present in the corpus. Some queries must require joining multiple durable records. Gold answers are evaluator-only.
